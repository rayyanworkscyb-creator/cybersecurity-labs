# 🛡️ Cybersecurity Labs

Hands-on cybersecurity labs and notes documenting my journey as a Cybersecurity student.

This repository contains practical exercises covering cybersecurity fundamentals, Linux, networking, reconnaissance, enumeration, and security analysis.

> ⚠️ All testing is performed only in authorized labs, CTFs, virtual machines, or systems where permission has been granted.

---

## 🎯 Objectives

- Build practical cybersecurity skills
- Understand Linux and networking fundamentals
- Learn reconnaissance and enumeration
- Practice security analysis
- Document methodologies and findings
- Develop a strong cybersecurity portfolio
